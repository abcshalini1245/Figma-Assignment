# Reelax Assignment

A Pixel perfect React JS implementation of the provided Figma design using reusable components, responsive layouts, and modern UI practices.

---

## 🚀 Tech Stack

- React JS
- Vite
- Tailwind CSS
- Lucide React
- JavaScript (ES6+)

---

## ✨ Features

- Pixel-perfect Figma implementation
- Responsive layout
- Reusable component-based architecture
- Clean folder structure
- Modern UI design
- Interactive checkout flow
- Dynamic order summary section
- Coupon and wallet integration UI
- Tailwind CSS styling

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone <https://github.com/abcshalini1245/Figma-Assignment>
```

Move into the project folder:

```bash
cd reelax-assignment
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
